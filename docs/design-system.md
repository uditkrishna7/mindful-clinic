# Design System

## Brand Personality

The website should feel:

- Calm
- Trustworthy
- Professional
- Modern
- Evidence-Based
- Approachable

---

# Visual Style

Minimal luxury.

Inspired by Apple, Linear and Headspace.

No unnecessary gradients.

Plenty of whitespace.

Rounded corners.

Smooth animations.

Readable typography.
